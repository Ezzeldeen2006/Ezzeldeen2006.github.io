Huffman File Compressor

Huffman-coded file compressor reaching roughly 40% reduction on text, with a C/C++ core, multi-threaded I/O, and a C# WinForms front end over it.

  • Algorithms
  • C/C++
  • C#
  • Concurrency
  • WinForms
Repository ↗

Systems implemented

  • Huffman coding from start to finish: counting symbol frequencies, building the code tree and packing the output bit by bit. Text files shrink by about 40%. The decoder has to rebuild the exact same tree from the compressed file, so the format has to carry enough information to do that.
  • Multi-threaded file I/O, so reading and writing run at the same time instead of one after the other. On large files most of the time is spent waiting on the disk, which is where threads help most.
  • A C/C++ core with a C# WinForms interface on top. The two sides manage memory differently and fail differently, so the boundary between them needed care, and progress updates had to cross it without freezing the UI.
  • Live progress reporting, which meant structuring the compression loop so it can say how far along it is.
